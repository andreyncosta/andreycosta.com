# andreycosta.com

Personal website — hosted on Hostinger at [andreycosta.com](https://andreycosta.com).

Built with zero frameworks. Semantic HTML, vanilla CSS/JS, editorial aesthetic.
Auto-deployed to Hostinger on every push to `main`.

## Languages (PT / EN)

Every public page is bilingual on the same URL. `assets/i18n.js` (loaded in `<head>`, no `defer`)
picks the language from `?lang=pt|en`, then the visitor's saved choice, then the browser, and
`assets/site.css` hides the inactive copy:

- Static text: write both copies, `<span lang="pt">…</span><span lang="en">…</span>` (or whole blocks with `lang`).
- Attributes and `<option>`/`<title>` text: `data-i18n-attr="placeholder"` + `data-pt-placeholder` / `data-en-placeholder` (`text` swaps textContent).
- Page title: `data-pt-title` / `data-en-title` on `<html>`.
- Script-built text: `siteLang.t(pt, en)`, and re-render on `siteLang.on(fn)`.
- Toggle: any `[data-set-lang="pt|en"]` button.

The rental contract text stays in Portuguese (Brazilian law); AI prompts in the photo quiz stay in English.

## Pages

### `/observatorio-fiscal/` — Brazilian Fiscal Observatory

Official RTN monthly nominal and real series, period filters, interactive SVG chart,
revenue/expense composition, accessible monthly table and CSV/JSON downloads.
Static snapshot generated by the validated `brazil-fiscal-data` pipeline. No runtime backend.
Data: Treasury National Secretariat, ODbL; attribution and methodology are on the page.
To update, run the data pipeline and export with:
`python exports/export_dashboard.py --output ../andreycosta.com/observatorio-fiscal/dataset.json`.
Only a successfully validated snapshot should be committed for deployment.

### `/` — Homepage
Editorial layout. Cormorant Garamond display, DM Mono for data labels, noise texture overlay.
Links to all active projects, research, and writing.

### `/curriculum` — CV
Bilingual (PT/EN) with client-side language toggle. No page reload.
PDF download for both languages. Print stylesheet included.

### `/contrato` — Contract Generator
Client-side rental contract generator. No server, no storage.

### `/emendas-parlamentares` — Parliamentary Amendments Dashboard
Interactive analytical panel for Brazilian federal parliamentary budget amendments.
Chart.js visualizations, filter system, anomaly detection. Built entirely in-browser.
